# Data Release

Post-level data behind *Who Let the Dogs Out? Auditing Dogwhistle Coverage in
Hate Speech Benchmarks Across Target Groups* (WOAH 2026).

**This release contains no post text.** Every post is identified by its
source dataset's own ID, and every label from a source dataset sits beside the
labels this project derived. To see a post's text, download the source
dataset yourself (see [Getting the post text](#getting-the-post-text)).

Everything here is generated by `python -m audit_pipeline.build_release`
from the pipeline's outputs; the build fails if any file contains post text.

## Contents

| Path | Rows | What it is |
|---|---|---|
| `corpus/union_primary.tsv` | 59,210 | The benchmark union used for the primary audit: HateXplain + Measuring Hate Speech, one row per post |
| `corpus/union_with_implicit_hate.tsv` | 79,237 | The same union with Implicit Hate added (paper §5.4 / Appendix G) |
| `matches/matches_primary.tsv` | 5,474 | Every dogwhistle surface-form match in the primary union, one row per (post, dogwhistle, target) |
| `matches/matches_with_implicit_hate.tsv` | 7,387 | The same for the Implicit Hate–inclusive union |
| `glossary/glossary_taxonomy_mapping.tsv` | 497 | Our mapping of the 340 Mendelsohn glossary entries to target groups and coding levels, one row per (entry, target) |
| `fpr/fpr_judgments.tsv` | 225 | The false-positive-rate annotation sample: both annotators' judgments for each matched post |
| `fpr/fpr_reportable_metrics.txt` | — | FPR and agreement numbers reported in the paper |
| `audit_results/` | — | Every Stage 1–4 result table, for the primary analysis, the tier-1+2 robustness check, and the Implicit Hate comparison |

The corpora are the union *after* low-support target groups were filtered out
and *before* text-level deduplication, so the same text can appear under more
than one post ID; the audit counts such posts once.

## Post IDs

| `dataset` | `post_id` is | Source |
|---|---|---|
| `hatexplain` | The HateXplain post ID (a key of `dataset.json`, e.g. `1179055004553900032_twitter`) | [hate-alert/HateXplain](https://github.com/hate-alert/HateXplain) |
| `mhs` | The Measuring Hate Speech `comment_id` | [ucberkeley-dlab/measuring-hate-speech](https://huggingface.co/datasets/ucberkeley-dlab/measuring-hate-speech) |
| `elsherief` | The 0-based data-row index into Implicit Hate's `implicit_hate_v1_stg1_posts.tsv` | [SALT-NLP/implicit-hate](https://github.com/SALT-NLP/implicit-hate) |

Implicit Hate posts are identified by row index, not tweet ID, on purpose: the
Implicit Hate authors distribute post text without tweet IDs, and this release
does not re-link the two.

IDs are unique only within a dataset (an MHS `comment_id` and an Implicit Hate
row index can be the same number), so always join on `dataset` and
`post_id` together. In `matches/` and `fpr/`, `post_ids` lists every ID that
shares the matched text, separated by `;`.

## Getting the post text

Each source dataset has its own terms of use; obtain it from its authors.

```python
import json
import pandas as pd

corpus = pd.read_csv("release/corpus/union_with_implicit_hate.tsv", sep="\t", dtype=str)

# HateXplain: dataset.json maps post ID -> record with tokenized text
hx = json.load(open("dataset.json"))
hx_text = pd.DataFrame(
    {"post_id": list(hx), "text": [" ".join(r["post_tokens"]) for r in hx.values()], "dataset": "hatexplain"}
)

# Measuring Hate Speech: one row per (comment, annotator); keep one per comment
mhs = pd.read_parquet("hf://datasets/ucberkeley-dlab/measuring-hate-speech/data/train-00000-of-00001.parquet")
mhs_text = mhs.drop_duplicates("comment_id")[["comment_id", "text"]].rename(columns={"comment_id": "post_id"})
mhs_text = mhs_text.astype({"post_id": str}).assign(dataset="mhs")

# Implicit Hate: post_id is the row index of implicit_hate_v1_stg1_posts.tsv
ih = pd.read_csv("implicit_hate_v1_stg1_posts.tsv", sep="\t")
ih_text = pd.DataFrame({"post_id": ih.index.astype(str), "text": ih["post"], "dataset": "elsherief"})

texts = pd.concat([hx_text, mhs_text, ih_text])
corpus = corpus.merge(texts, on=["dataset", "post_id"], how="left")
```

To rebuild every file here from the source datasets instead, run the full
pipeline described in the repository [README](../README.md).

## Column reference

Columns prefixed `source_` come from the source dataset (lightly reformatted,
as noted). Every other label column is derived by this project.

### `corpus/`

| Column | Origin | Meaning |
|---|---|---|
| `post_id`, `dataset` | source | See [Post IDs](#post-ids) |
| `source_raw_label` | source | HateXplain: the per-annotator label records (JSON). MHS: the mean of the post's `hate_speech_score` across its annotations. Implicit Hate: the stage-1 `class` (`explicit_hate`, `implicit_hate`, `not_hate`) |
| `source_targets` | source | The dataset's own target-group annotations, as a list (HateXplain: annotator targets; MHS: `target_*` flags; Implicit Hate: stage-3 free-text targets, `unknown` when absent) |
| `source_n_annotations` | source | MHS only: number of annotations aggregated into the post |
| `binary_hate` | derived | Binarized benchmark label. HateXplain: 1 if more than half of annotators chose `hatespeech`. MHS: 1 if the mean `hate_speech_score` is at least 0.5. Implicit Hate: 1 for `explicit_hate` or `implicit_hate` |
| `label_conflict`, `conflict_datasets` | derived | Whether the same normalized text appears in several datasets with different `binary_hate`; if so, the hateful label was applied to all copies |
| `target_std` | derived | `source_targets` mapped to canonical spellings |
| `direct_annotation_label` | derived | Schema labels from our annotators' mapping of each raw target label (labels task) |
| `glossary_annotation_label` | derived | Schema labels inferred from glossary dogwhistles found in the post (glossary task) |
| `legacy_backfill_label` | derived | Schema labels mapped directly from `target_std` |
| `cleaned_label` | derived | Union of the three label columns above |
| `matched_glossary_terms` | derived | Glossary dogwhistles whose surface forms occur in the post |
| `glossary_mapped_taxonomy_levels`, `glossary_mapped_targets`, `glossary_mapped_types` | derived | Target categories, targets, and dogwhistle types of `matched_glossary_terms` |

Both annotation tasks combine the two annotators' labels by plain union; see
[the note on disagreement resolution](../annotations/README.md#note-on-disagreement-resolution-vs-the-paper).

### `matches/`

| Column | Meaning |
|---|---|
| `post_ids`, `dataset` | The matched post(s) |
| `binary_hate`, `source_targets` | As in `corpus/` |
| `found_forms` | Surface form(s) that matched |
| `dogwhistle` | Glossary entry the surface form belongs to |
| `taxonomy_level`, `target` | Target category (e.g. `race`) and target group (e.g. `black`) |
| `type` | Mendelsohn dogwhistle type |
| `coding_level` | Coding sophistication level L1–L4, derived from `type` |
| `is_self_referential` | Whether the dogwhistle signals in-group membership rather than an external target |

### `glossary/glossary_taxonomy_mapping.tsv`

| Column | Meaning |
|---|---|
| `dogwhistle` | Glossary entry (normalized) |
| `surface_forms` | Strings matched in posts, `;`-separated |
| `taxonomy_level`, `target` | Target category and group, from the glossary annotation task |
| `type` | Mendelsohn dogwhistle type |
| `coding_level` | Coding level derived from `type` |
| `tier` | Provenance tier of the entry's source (1 = editorially accountable, 2 = named author, 3 = community-edited) |

### `fpr/fpr_judgments.tsv`

| Column | Meaning |
|---|---|
| `row_id` | Sample item ID |
| `post_ids`, `dataset` | The sampled post(s) |
| `dogwhistle`, `matched_surface_form`, `coding_level`, `all_target_groups` | The match being judged |
| `binary_hate` | The benchmark's binarized label for the post |
| `judgment_annotator1`, `judgment_annotator2` | Each annotator's judgment of whether the post uses the term hatefully: `Hateful`, `Not Hateful`, or `Unknown` (the paper's "Unclear") |

The annotators' free-text notes are not released.

The sample was drawn while the union still included Implicit Hate, so 47 of
the 225 items are Implicit Hate posts; the per-level FPR estimates in the
paper are computed over all 225.

### `audit_results/`

Stage outputs copied unchanged (except that `s1_matches.tsv`, which contains
post text, is released as `matches/` instead). Each table is described in
[`audit_pipeline/README.md`](../audit_pipeline/README.md#outputs); `robustness_check/README.md` documents the robustness comparison.
`*_tier12` directories hold the tier-1+2 robustness check, and
`stage1_with_elsherief` holds Stage 1 for the Implicit Hate–inclusive union.
